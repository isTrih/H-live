# 文档范围

`user/` 是使用说明；`release/` 是构建和更新渠道说明；`engineering/` 中带版本号或日期的文件属于历史设计与验收笔记；`research/` 记录固定来源的调研。

公开副本中的直播间、主播示例 ID 已匿名化，示例不是推荐监控对象。历史笔记提及的 `build/`、诊断、日志和真实抓包不随源码公开；不能把这些链接当作本仓库附带的可复现实测证据。活动二进制测试夹具为合成数据，可通过 `scripts/generate_activity_fixtures.py` 重建。

当前产品范围以根目录 README 为准：0.2.4 已停用新增礼物采集，仅保留历史记录。旧版本文档提及的礼物采集、登录排查或下一步账号对照不属于现行需求。

完整 Rust 后端迁移尚未完成，见 [迁移计划](engineering/RUST_MIGRATION.md)。当前可运行程序仍包含 Python/V8；Tauri 界面和 Rust 数据处理核心已经存在。
