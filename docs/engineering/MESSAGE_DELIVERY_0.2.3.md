# 互动消息诊断与 0.2.3 修复

## 已确认原因与证据

1. **已存入库的低频消息在实时视图消失。** 旧视图在全局 1200 条 IPC 缓存上筛选。注入礼物、活动、表情、粉丝团、关注 / 分享各一条，再注入 1500 条进入消息，礼物分类为空。红灯证据为 `build/diagnostics/rare-message-cache-red.log`。新视图调用 Rust 归档查询，按分类、入口 ID 读取最近 150 条；原场景绿灯为 `rare-message-cache-green.log`。这能恢复已归档的显示，不能补回从未收到的消息。
2. **实际福袋同步未被识别。** 用户指定公开房间的匿名 WSS 包包含 `WebcastRoomDataSyncMessage`，业务键为 `LotteryInfoSyncData`。旧解码器返回忽略。保留公共活动字段的脱敏真实包回放已验证新解析器输出福袋活动，且可经生产采集回调、场次校验写库，再通过实时查询返回。
3. **实际红包预告未被识别。** 同次采样出现 `WebcastPreviewCjRpMessage`，现已补充解析。金额原始数值保留，不推测币种单位，不生成发送人；图标链接和参与用户信息不进入回归夹具。

## 查询与显示范围

- 全部分类不显示进入消息；进入按钮移除，原归档和导出能力保留。
- 全部视图合并七类各最多 150 个索引命中，再取最新 150 个。避免进入消息洪峰使排除查询退化为无界反向扫描。单类 / 指定房间均使用追加索引，参数绑定。
- 内容预览最多 4096 UTF-8 字节，总行数据最多 512 KiB；大整数 ID 以文本传输；数据库保留完整原文。仅活动种类进入实时摘要，不把任意 payload JSON 透传前端。
- 查询使用一致只读快照。暂停显示固定到上次读取的全局归档游标，分类切换仍可读取该游标之前的数据；恢复时解除游标。切换筛选及删除操作使旧异步回复失效。
- schema 仍为 v3，三项查询索引为追加结构。旧消息、序号和外键由升级验证保护。

## 后续决策（0.2.4）

现场游客连接能收到聊天和在线状态，但未收到原始礼物包；连接成功不能证明所有消息下发。社区反馈也不足以承诺无需登录的稳定礼物记录。[上游讨论 #164](https://github.com/saermart/DouyinLiveWebFetcher/issues/164)

用户已明确不使用登录 Cookie，当前版本停用新增礼物归档、计数和实时展示，仅保留历史记录查询/导出。不要求用户再次送礼或配置账号。本文前面的礼物显示回归描述的是历史问题，不能视为当前仍支持采集礼物。

内部历史诊断与抓包不随公开仓库发布。公开活动二进制回归夹具全部替换为合成数据；上述真实包观察属于先前内部验证记录，不是本仓库可重放的现场证明。
