# 0.3.0 验收与边界

本记录面向 Windows x64 的本机验证；所有数据库升级、代理凭据、安装和删除测试均使用隔离合成数据，不读取或修改真实用户数据。

## 已取得的证据

- 共 173 项通过：core 92、runtime 24、桌面门禁 5、前端 52。前端另连续执行三轮均通过；最终网络与出口生命周期优化后 runtime 24 项再次通过。格式检查与 Clippy 通过；Clippy 保留既有 core 多参数函数接口的豁免。
- 原生签名通过五组上游向量及随机边界；同一个参数结构生成签名和 WSS query，没有使用固定旧 did/cursor。
- 真实游客 WSS 的 60 秒观察已成功建立连接并保存两条进入事件；没有在该窗口收到聊天。随后延长观察时该主播已下播，不把零消息判为采集成功。聊天完整链路使用可解码合成帧验证。
- 合成礼物通过实际解析和采集链路后不入库、不展示、不计数；旧库礼物仍能查询和导出。
- 用真实 0.2.4 原生模块生成隔离数据库及 DPAPI 配置，再由 0.3.0 打开。anchors、sessions、messages、session_monitor_durations、audience_minutes、sqlite_sequence 六表逐值不变；代理可读并重新加密，登录字段不使用，CSV/XLSX 可导出。
- CONNECT 认证失败、临时不可信证书在 HTTP/WSS 两条路径均拒绝；订阅拒绝非 HTTPS、私网和受限地址。测试没有更改系统证书库。
- 同场续时排除停止间隔、更新确认暂停及取消恢复、删除门禁、退出等待通过本地契约测试。

## 离线性能

通过生产采集、解码、SQLite 和分析路径，测试适配器模拟网络：300 个任务、50 个开播房、51 个出口，50 条连接集中断开并重建。

| 指标 | 本机结果 |
| --- | --- |
| 峰值并发模拟连接 | 50 |
| 累计创建连接 | 100 |
| 已保存聊天 / 礼物 | 3400 / 0 |
| 启动至 50 连接 | 6.57 秒 |
| 停止耗时 | 0.072 秒 |
| 观察到的进程 RSS 峰值 | 27.8 MiB |
| 最多采集相关线程 | 16 |
| 进程 CPU / 单核心容量 | 约 13.0% |
| 观察时长 | 28.45 秒 |

以上仅 Rust 后端，不含 WebView 内存；不是长时间压力测试，也不代表真实 50 个抖音房间或代理的可用率。报告末尾的队列指标是停止前快照，最终落库 3400 条及所有 worker 退出由停止后的 SQL 与退出结果确认。

## 发行检查

- 正式可执行程序的离线自检通过：空初始列表、移除登录接口、归档读写、真实 CSV/XLSX 任务及所有后台退出。
- 独立命名的 NSIS 测试产品完成新装、更新模式重装、0.2.4 → 0.3.0 升级、卸载与数据哨兵保留。未覆盖用户真实安装。升级发现 /UPDATE 会遗留旧 engine，已添加仅针对安装目录内已识别旧 engine 的清理和顶层重解析目录拒绝规则；修复后升级通过。
- 保留应用标识、二进制名、更新公钥及 CDN 端点。签名验收通过：独立 Rust minisign verifier 验证原文件成功、拒绝内存单比特修改，SHA256 与 latest.json 均一致；不读取私钥、不修改安装器。CDN ZIP 校验五项文件及逐项哈希，上传须另由维护者执行。
- 主 Agent 查看 1280×720 的看板、移除登录入口后的设置与主播详情实际画面，未发现重叠或文字裁切；未进行独立视觉评审，也未修改整体风格。前端截图数据是模拟预览，不能作为采集证据。
- 源码提交前检查已知用户凭据/ID、常见 token/私钥模式、字体与许可哈希和排除目录；这不是完整的安全审计。

## 未覆盖与行为限制

没有完成真实 50 房间长期监控或与旧版同条件性能对照，不承诺平台限流消失。游客消息范围由平台决定；断线期间内容无法补采。当前不做登录和礼物采集，也没有独立安全审计。历史工程文档中的 Python、schema v1/v2 和旧版礼物实验只描述对应版本，不代表当前架构。
