# 氢看直播桌面界面设计

目标是快速辨认哪些主播开播，并直接操作监控任务。界面遵循用户指定的顶部菜单、浅色圆角、多宫格、绿色开播、灰色未开播和红色异常提示方向；保留 Windows 真实最小化、最大化、关闭与单实例行为。圆角由透明无边框窗口内的界面绘制，最大化时取消，不冒充 macOS 系统菜单。

## 布局与卡片

顶部导航、状态汇总、搜索筛选和展开后的批量操作栏保持固定，下方任务区域独立滚动。底部整条状态栏已移除，主播计数使用顶部汇总。默认窗口 1400×900，最小窗口 1040×700；普通缩放下对应六列和四列宫格。卡片固定高 **168px**，间距 **14px**，根据可用宽度计算列数。

宫格采用虚拟连续滚动，仅绘制可见区域及邻近两行，顶部和底部占位保持滚动位置；无需分页。滚出视野不影响后台采集。列表视图仍可用于逐行查看，搜索、筛选和排序适用于完整任务列表。确认开播的主播优先并按当前在线人数倒序，未开播区域默认折叠；未知状态不归入未开播。移除「开播优先」说明，内部控件统一轻圆角。

卡片只保留名称、带状态点的直播状态、该真实场次的累计监控时长和当前在线人数。计时显示 `HH:mm:ss`，未知时间或人数显示「—」；人数为零时显示 0。仅累计已观察到的开播监控区间，同场停止或重启后继续已保存值，中断及停止间隔不计，新场另计；强退恢复最近成功检查点，不补停机间隔，显示时长不覆盖真实开播归档字段。场次、消息计数、代理和其他诊断数据移入详情中的「连接信息」，场次仍正常归档。连接异常、等待代理和未监控分别标识，不凭过期的状态显示绿色开播。

整张卡片可点击打开**居中模态框**。卡片底部提供开始/停止图标及描边「打开直播间」按钮；停止使用红色方块图标，图标有悬停提示和可访问名称，打开按钮调用系统默认浏览器。复选框只在「批量选择」模式显示，「选择可见」仅选择当前视野中的卡片，滚动后可继续选择。

详情模态框首先显示名称、状态、人数和时长；「连接信息」与「独立登录凭据」均折叠收纳，支持改名、Cookie 写入/清除、打开直播间与移除任务。整卡点击层保持透明，已覆盖通用按钮 hover/active 样式，避免悬停时遮住卡片内容；内层操作按钮单独处理。

## 颜色、字体与动效

开播使用浅绿背景 `#e2f2e6`、边框 `#b8d6bf` 和状态色 `#1d7b43`；未开播为灰色卡片，异常使用红色提示。页面和顶部菜单底色为纯白 `#ffffff`，正文 `#252a31`。状态同时有文字，不只依赖颜色。主要操作采用中性深灰，避免与开播颜色混淆。

用户提供的两个字体包已作为本地资源收录于 `src/fonts/`：默认抖音美好体 `DouyinSansBold.otf`，实际字重 700；可在「设置 → 界面字体」切换寒蝉半圆体 `ChillRoundM.otf`，实际字重 400。选择通过 `localStorage` 的 `livescope.appearance.font` 保存，重启后沿用。`font-synthesis: none` 禁止浏览器伪造粗体或斜体；保留系统字体作为缺字后备，不使用远程字体服务。两份 OFL 与来源说明保存在 `src/fonts/licenses/`，具体文件和哈希见 `font-manifest.json`。

开播状态点使用轻微呼吸效果；按键、模态框和首屏有短暂反馈，并尊重减少动态效果设置。高频数据变化不反复播放卡片入场动画，不引入直播画面、远程头像或装饰插画。

应用标识更新为薄荷绿小电视，外壳采用 5px 的 5% 灰色边框 `#f2f2f2`，普通窗口外圆角为 14px。按钮和状态标签使用独立 UI 字体别名调整字体度量，修正汉字与图标的视觉中心；正文和内容消息仍使用原字体度量，字体文件本身未修改。

设置页提供「关于与更新」，版本号由当前应用配置统一提供；详细日志以居中弹窗呈现，最大宽度 760px，标题固定，正文独立滚动。远端更新说明仅渲染转义后的标题、列表和段落，不能注入 HTML。检查更新与安装分开，默认启动后及每小时检查更新，仅提示。确认后先完成下载/验签，再自动暂停监控并保存恢复列表，更新后重新打开恢复原活动任务，后台核验导出与归档状态。

## 数据更新与桌面集成

采集、代理检测与导出在后台进行，界面按批次轮询 JSON RPC，避免逐消息桌面 IPC。实时内容最多显示最近 150 条匹配记录，界面缓存与完整 SQLite 归档独立。当前在线人数在看板显示，并按分钟保存独立场次统计，不混入聊天消息表和原始七列导出。

代理页面将「获取并检测」与「启用代理」分开。每个手动批次以 50 个新候选为目标，显示检测进度与通过数；进行中重复点击不排入新批次，来源不足时明确显示部分完成。本次应用运行中的失败地址在模式切换后仍排除，不将候选数包装成可用代理数。

代理来源可切换公共池或已导入列表。粘贴或选择文件后先预览有效、重复及无效数量，再明确导入；账号密码不在预览和管理列表中回显。切换来源失败时恢复原选择，批次进行时禁用冲突操作。

应用为单实例，重复启动唤醒现有窗口。已在本机 Windows 核验 PerMonitorV2，当前显示器 DPI 96；其他显示器缩放组合仍需独立验证。原生开发窗口已启动供用户预览，使用实际后台和正常用户数据目录，记录见 `build/dev-preview/launch-report.json`。浏览器开发预览的模拟数据与原生实际连接分开，生产界面不会以模拟数据代替连接结果。

## 验证与后续检查

虚拟宫格的两项 JavaScript 几何测试覆盖列数、滚动范围和占位高度；默认浏览器 URL 的两项 Rust 测试覆盖合法房间地址和非法输入拒绝。字体默认选择、切换与持久化已通过浏览器检查。生命周期、当前版本网络及容量结论见 [EVALUATION.md](EVALUATION.md)。

此前独立视觉审阅为 7/10，随后已增加小图标提示、精简卡片信息、固定顶部操作区，并改为居中详情和连续滚动；新版静态视觉复核为 **8/10**，记录见 `.artifacts/ui/visual-review.md`。截图位于 `.artifacts/ui/livescope-final-1400.jpg` 与 `livescope-final-1040.jpg`，仅表示当时的界面状态，具体后续变更以当前源码和最新截图为准。静态评分不代表真实代理连接或全天运行验证。


## 0.2.2 场次分析

主播详情扩展为最大 1040px 中心弹窗，标题与底部操作固定，正文独立滚动。场次与样本分别有有界阅读区，避免一次渲染长历史；保留清楚的边界和滚动链约束。摘要与表格统一「累计监控」口径。场次每页 20 行、样本每页 30 条，未完成有效率留空。规则折叠，筛选原因时同屏说明阈值，减少重复原因标签和重复计数。

沿用模态入场、按钮反馈，表格选择有 120ms 背景反馈，尊重减少动态效果；高频刷新不重复入场。独立评审一轮、不打分，按意见收紧摘要留白、统一时长口径、使用红色实心停止图标与中性按钮、降低日期边框并补原因依据。保留嵌套阅读区用于有界历史，标题/操作保持固定。证据：build/ui-0.2.2/，开发模拟数据不代表真实平台采集。
