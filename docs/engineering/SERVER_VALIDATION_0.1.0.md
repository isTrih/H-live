# H-live Server 0.1.0 验证记录

目标为 Linux amd64 + Docker；桌面产品仍为 0.3.0。服务端不使用抖音登录 Cookie、不新增礼物记录、不播放或录制视频。此记录不等于独立安全审计或真实直播间容量保证。

## 本机验证

- Windows Rust 工具链完成 workspace 回归：核心 92、运行时 24、服务端 9 项通过；桌面集成另有 5 项通过。前端 54 项通过，桌面及服务端两种 Vite 构建通过。
- 服务端 crate 的 Clippy（仅本 crate、全部 targets、启用 test-support、`-D warnings`）通过。未重构核心现有两个参数数量 lint；没有把全仓库严格 Clippy 宣称为通过。
- 9 项服务端测试包含认证加密及篡改/错密钥拒绝、密钥初始化幂等、认证与 Cookie/CSRF/Origin 门禁、会话撤销、超限请求体、无任意命令/路径接口、单实例数据锁、任务恢复和停止意图、同一场次历史、礼物过滤、导出与重启后下载、持久化失败不启动采集，以及代理凭据重启读取。
- 对早期一次“读取历史主播失败”，最小代理重启测试和三轮集成复跑没有复现；服务任务控制已改为只读取配置与实际句柄，避免依赖归档快照。最终又完成十轮、50 次集成场景，全部通过。没有声称已证明 SQLite 报错根因，后续仍需长期观察数据库忙和存储告警。
- 主 Agent 实际查看隔离预览中的登录页、空看板和设置，操作登录、导入测试主播、刷新后保留及退出后重新登录。使用合成凭据和独立空目录，未访问用户桌面数据库，也未启动真实房间采集；临时预览已关闭。仅局部适配与自检，未做独立视觉评分。
- 干净 npm 安装发现旧锁文件错误引用未发布的 `tinyglobby 0.2.37`；使用官方元数据重新解析为 0.2.17，锁文件只改该版本/URL及 Vite 的声明范围，完整性哈希保持一致。隔离目录的 `npm ci --ignore-scripts` 与 web 构建已通过，没有删除共享 node_modules 链接。
- 最终 Git 源码检查 224 个文件，不含 Python 源码、字节码、扩展、Notebook、依赖清单、shebang 或 Python 文档代码块。旧版本 Git 历史按原要求保留。

## 边界

没有提供用户服务器连接信息，尚未部署到用户服务器；没有完成真实 50 房间或 24 小时生产观察。CI 合成 WSS 输入只验证本程序调度、解析、归档与资源行为，不证明抖音或某个代理下发完整消息。采集断线、停机和平台未下发的消息不能补回。

HTTP 健康检查仅表示控制线程就绪，不证明采集健康。控制线程异常退出会停止 HTTP 服务并以失败退出，交由 Docker 重启策略恢复。单机单实例没有多节点容灾，备份和密钥保管仍需维护者落实。

服务端更新使用 Docker 镜像，未修改桌面更新密钥、应用标识或 CDN `latest.json`。Windows DPAPI 代理密文不能跨平台解密，迁移只复制停机后的历史数据库并重新导入主播与代理。
