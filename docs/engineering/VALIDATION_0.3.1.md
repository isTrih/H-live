# 0.3.1 桌面 / 0.1.1 服务端发布验证

本版沿用 0.3.0 的应用标识、数据目录、SQLite schema、更新公钥和 HTTPS CDN 地址，不再引入抖音登录 Cookie 或新礼物记录。

功能基线提交 `163581a` 已通过 [Linux CI](https://github.com/isTrih/H-live/actions/runs/39192644727)，包含新构建生产镜像的单容器生命周期、持久化数据/密钥、鉴权、停止写入与重新创建、丢失密钥拒绝，以及 300 合成任务、50 连接和集中重连。最终版本号提交另行构建验收后发布；该基线结果不代替最终发行文件校验。

本机功能回归：56 项前端测试，Rust 工作区归档/导出/迁移/时长/质量统计/采集测试，Salvo 鉴权、任务恢复及下载集成测试，Tauri 编译检查。界面在 1440×900、1280×800 与双倍像素密度检查；性能数字与实际范围见 [ADAPTIVE_POLLING.md](ADAPTIVE_POLLING.md)。

发布检查包括实际目录版程序离线自检、独立 NSIS 测试身份的新装及 0.3.0 升级、卸载与数据保留、原公钥签名验证与篡改拒绝、CDN ZIP 白名单及逐文件哈希。结果由本机 `build/` 报告和 GitHub Release 附件提供；私钥不进入源码、日志或发布包。

服务端使用独立 `server-v0.1.1` 发布线，不抢占桌面 Latest。发布附件为 Linux amd64 Docker 镜像归档、单容器脚本、SHA256SUMS、构建来源及验收结果；CI 使用合成数据，尚未在用户服务器完成真实平台 50 房间或 24 小时运行验收。
