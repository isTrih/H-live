# 直播打点与切片下载

沿用现有浅底、绿色操作和紧凑工具布局。主动作是在直播当下记录时刻，之后按场次回看、精选并下载；不另起一套播放器或下载队列。

- 看板的开播主播提供快捷打点，详情页支持标题、备注、勾选精选。时间由后端记录，绑定真实主播与场次，重启后保留。
- 打点映射到原有回放进度条，用旗标区别于 AI 亮点。录像时间缺口不补成有效片段；无录像仍可记录打点。
- 精选片段默认保留打点前 15 秒、后 30 秒，支持调整、边界裁剪和已有框选编辑；总长沿用 15 分钟上限。
- 下载任务按北京时间的创建日期分组，日期、状态、关键词筛选与分页保留输入焦点。历史独立索引，避免随着队列清理丢失。
- 下载设置分别编辑根目录、相对文件夹规则和文件名规则，变量列表默认折叠。路径预览、失败提示和保存后读回不可省略。
- 回看沿用原进度条，刻度和播放位置显示真实世界时间；时区默认 `Asia/Shanghai`，设置可选择 IANA 时区。录像用自身 PDT 对齐，与弹幕偏移分离；跨日显示日期，缺少可靠锚点不虚构录像时刻。
- 原生覆盖层只接收当前附近的紧凑时间映射，不在每次刷新传整段录像清单；暂停、全屏和切片位置继续使用媒体秒数。
- 复用现有按钮按压反馈，精选行用短促底色过渡，时间轴旗标悬停改变底色；减少动态装饰并遵守减少动效偏好。

验证重点：跨场次晚到响应、重复操作幂等、保存失败保护草稿、部分批量失败后的继续、重启持久化、模板目录边界与重名保护、分页不丢历史。

本轮访问本地预览时被浏览器 URL 安全策略拒绝。未使用其他浏览器或底层接口绕过，因此没有新的实际界面截图或视觉评分；功能通过模块与 Runtime 集成回归验收。
