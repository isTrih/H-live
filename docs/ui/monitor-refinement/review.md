# 监控与回放界面调整 · 2026-10-23

沿用浅绿、高密度的直播监控界面，让看板承担主入口，低频工具退入设置。

- 累计时长逐位底片、中心接缝和 280 ms 翻页；初次挂载直接显示，仅变化位播放。系统减少动画偏好下直接更新数字。
- 主导航保留监控看板、导出数据、设置。消息流由看板工具栏进入，仍支持主播与消息分类筛选。
- 代理池与诊断默认折叠。代理关闭时使用直连，自动订阅刷新暂停；折叠时不查询代理状态或构建任务分配表。
- 红包与福袋为独立 26×26 px 时间轴标记，碰撞时分行；悬停与键盘聚焦展示详情，点击定位并显示活动通知。通知时间、观察时间、开奖时间分开表述，聊天面积图口径保持不变。

实际预览检查：1280×720；验证导航、消息流、诊断开关、代理折叠、活动点击回放及固定标记尺寸。109 项前端、181 项 Rust 回归通过。独立审查者实际查看下面四张图片，完成一轮受影响区域的视觉审查，未发现阻断问题。

图片使用开发预览的模拟数据；活动去重、时间可靠性、代理与日志持久化另由真实后端路径的临时数据测试验证。
