# 官网与更新提示

北极星：以氢看直播的绿色电视形象为视觉主角，让人第一眼认出应用，直接下载，再往下看实际使用界面。

已按用户意见从浅色短页改为深色 Hero 长页。配色来自现有应用图标：近黑绿背景、薄荷绿操作和浅色文字。Hero 用原始高分辨率品牌 PNG，未生成替代标志。下方分监控、回看、导出三个区域，配应用预览截图；截图来自模拟数据，不包含真实归档、API key 或系统配置。

主要状态：读取版本、可下载、网络或清单失败。下载 URL 来自签名清单，要求 HTTPS 同源；失败不显示虚构链接。图标、截图与 GSAP 3.13.0 全部内嵌为单 HTML。图片可点击放大，Escape 关闭。

动效分镜：首屏图标进入后轻浮动，消息形状的频谱缓动；向下滚动时角色缩小并上移，光晕缓慢扩散，交接至产品截图；截图通过遮罩展开，功能线条沿阅读方向出现。正文和下载按钮不做滚动缩放。遵循减少动态效果偏好。

保留必要名称、状态与动作；删除旧宣传口号、编号和三段重复介绍。桌面更新提示用红点加「新版本」文字，弹窗保留「稍后」，不会顶替用户正在使用的其他弹窗。
