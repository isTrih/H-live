# 氢看直播官网横向展示

用户进入官网先了解产品，最后抵达下载页。保留氢看图标、深墨绿与薄荷色品牌，使用现有产品截图形成五幕全屏展示：品牌、监控、回看、数据与备份、客户端下载。

页面主体固定在浏览器视口内，滚轮向下切换为横向下一幕，向上可返回。触控板连续惯性滚动只推进一次；支持触摸滑动、键盘方向键、Page Up / Down、Home / End 和底部导航。五秒未操作时自动切至下一幕，到下载页停止，不循环。按用户要求不显示自动播放控件；键盘聚焦正文时可用空格暂停。减少动态效果偏好默认关闭自动切换，手动切换立即到位。

GSAP 驱动横向轨道与首次进入时的标题、截图出场；按钮保留短促按下反馈，底部进度提示五秒停留时间。日志弹窗和后台标签页暂停计时，关闭或返回页面后重新计时，避免跳过内容。弹窗拥有独立纵向滚动；矮屏内容允许幕内滚动，浏览器页面本身不出现纵向长页。

首屏与顶部不放下载按钮。最后一幕从同目录 latest.json 读取已签名的 Windows 安装包地址与版本，仅接受原站点下与版本匹配的安装包路径；无效清单提供重试，不指向猜测地址。

右上角打开完整更新日志，独立 changelog.json 收录仓库中所有截至当前版本的桌面日志，按语义版本倒序排列，不补造发布日期。正文作为文本构建 DOM，不能执行其中的 HTML。

发布资源拆为 index.html、style.css、site.js、assets、vendor 和 changelog.json；图片与动画库均使用站内文件，不内嵌 base64，也不依赖外部 CDN。修改官网时保留 0.4.5 安装包及更新清单，使用单独网页刷新事务，保留旧站点快照后更新冻结摘要，再交付用户手动上传。

交互模型、日志生成及打包保护由定向测试覆盖；实际截图与视口核验记录保存在 build/release-site-horizontal/。

## 字体与素材精修（website_revision=3）

用户认为下载幕字形生硬；保留品牌与五幕结构，标题改用其指定字体候选中的得意黑，正文保持系统无衬线。官方完整 WOFF2、OFL 和来源记录放在 `release-site/fonts/`，不依赖字体 CDN。去掉下载图上覆盖的大字、自动播放按钮及重复的页头说明，右上新增用户提供的飞书反馈群链接；末幕不再显示继续向下滚动的提示。

标题采用逐行展开，截图侧向进入；吉祥物轻微漂浮，首屏波形呼应，下载按钮保留按下与箭头反馈。循环动画只在当前幕且页面可见时运行。实际读取两次可见变换，确认吉祥物与波形位置变化；也实际核验了自动推进与日志打开期间暂停。新回看图原样使用用户提供的 1400×900 JPEG，按 14:9 完整展示。

日志显示 `YY/MM/DD` 日期，共 19 版有发布清单、CHANGELOG 或已验证发布记录作为依据；0.1.0、0.1.1、0.2.0、0.2.1 明确显示日期未记录。本地来源记录保留在 `release-notes/release-dates.json`，官网 JSON 不包含私有快照路径或部署信息。未来打包自动保留首次日期，重打包不改历史日期。
