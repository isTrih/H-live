# 氢看直播 0.3.4

## 重启后恢复历史场次

- 修复重启后未开播主播的详情无法读取历史场次的问题。恢复已保存的真实主播 ID 与最近场次，无需等待主播再次开播。
- 旧版身份信息为空时，自动使用本机归档中能明确对应直播间入口 ID 的记录恢复；不按昵称猜测主播身份。没有可靠对应记录时仍保持待确认。
- 恢复的是已保存的身份与历史内容，开播状态仍以平台查询为准；不会补采未监控到的消息或停机时间。

## 详情状态与场次隔离

- 未确认正在直播的最近场次显示为「最近场」，只有真实开播中的场次显示「当前场」。下播后回放控件同步更新。
- 主播身份发生变化时，重置旧场次选择与亮点缓存，取消旧分析任务并忽略迟到结果，避免混入其他主播的历史。相同主播的普通刷新保留手动选择的历史场次。
