# 氢看直播 0.1.1

本次改善月度消息导出，监控与已保存的数据保持兼容。

## 导出改进

- 选择多位主播导出 XLSX 时，每位主播使用独立工作表，工作表名称采用主播显示名；单主播导出也使用该主播的工作表名称；所选主播没有当月记录时保留仅含表头的工作表。
- 对工作表名称中的非法字符、超长名称和重名进行处理；数据超过单表行数上限时继续写入续表，不静默截断。CSV 仍将所选主播写入一张平表。
- 在第 4 列新增「发消息人名字」，使用已归档的发送人昵称；缺失时留空，不用发送人 ID 补造。
- 导出顺序固定为七列：主播、直播间场次、发消息人ID、发消息人名字、消息类型、消息内容、发消息时间。
- 多主播默认文件名为「直播消息-2026-10.xlsx」，单主播为「直播消息-主播名-2026-10.xlsx」；CSV 使用相同规则和对应扩展名，月份随所选月份变化。

## 数据与兼容

- 长 ID 仍以文本保真；CSV 的公式前缀保护也覆盖新增昵称列。XLSX 仍不会将消息或昵称解释为公式。
- 月份继续使用上海时区，未知发送时间留空；导出使用一致快照并原子保存，取消或失败不覆盖旧目标文件。
- 沿用 0.1.0 的配置、内容数据库、安装更新渠道和签名公钥，无需重新录入主播或代理。
- 安装包和更新清单由维护者手动上传 CDN。离线构建、导出和隔离升级的验收范围见随包 EVALUATION.md；未上传前不表示线上更新已经生效。
