# H-live Server 0.1.1

## 调度与管理界面

- 同步桌面 0.3.1 的自适应离线查询：30–600 秒退避、近 28 天常播时间偏好、优先队列和等待提权。
- HTTP 444、请求错误及状态待确认继续执行错误退避，不把它们当成下播；已连接的 WSS 持续收消息。
- 精简管理轮询，避免反复传输代理库存及重建不变的界面；调整详情弹窗、月度归档、代理分配和设置布局。
- 保留原 SQLite、历史消息、累计监控时长、本地有效发言分析、在线指标和 CSV/XLSX 导出。

## Docker Engine 单容器

- 网页、Salvo API、采集、SQLite 和导出继续在一个应用容器中运行，同容器初始化密钥，Rust 为 PID 1，UID/GID 10001。
- SQLite 与任务、日志、导出和开播习惯保存在容器外持久化数据卷；密钥使用独立卷，升级沿用原卷，已有密钥不覆盖。
- 发布 Linux amd64 镜像归档、单容器部署脚本、构建来源和校验清单。默认不需要 Compose；历史 Compose 配置继续兼容。
- 发布构建验证当前镜像的单容器生命周期，不以旧版镜像的验收代替本版验证。

## 升级

先停止并备份原数据卷与原密钥卷，确认归档完成，再加载 0.1.1 镜像；移除旧应用容器本身后，使用新部署脚本和同一对卷重新创建。不要删除卷，不要同时运行两个实例访问同一份 SQLite。详细命令见 `docs/server/DOCKER_SINGLE.md`。

服务端使用独立版本线，不修改桌面 CDN 清单。仍不使用抖音登录 Cookie、不新增礼物记录；首次安装不预置主播。PostgreSQL 尚未实现。合成规模测试和容器健康检查不代表真实平台长期下发保证，尚未部署到用户服务器。
