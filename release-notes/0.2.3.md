# 氢看直播 0.2.3

本版修复实时消息分类遗漏，补充通过实际直播消息验证的福袋同步与红包预告解析。

## 实时消息

- 实时消息不再显示「进入直播间」，移除「进入」分类按钮；进入记录继续保存在归档，可按原方式导出。
- 礼物、红包 / 福袋、表情、粉丝团、关注 / 分享等分类改为从本机归档读取最近 150 条匹配消息，每两秒刷新。打开页面、重新启动或切换分类后，也能看到已保存的消息。
- 修复大量进入、点赞消息挤占共享缓存，导致低频互动已经入库、实时分类却显示为空的问题。
- 读取失败显示失败状态并重试，避免误报没有消息；切换主播或分类时丢弃过期请求，避免串行显示上一筛选结果。
- 暂停只暂停显示，消息采集继续。暂停后切换分类，仍停留在暂停时已读取的数据范围；恢复后显示新消息。
- 页面仅读取有界摘要，完整原文与结构化活动详情仍保存在归档，月度导出继续使用原七列。

## 福袋与红包

- 新增 `WebcastRoomDataSyncMessage` 中 `LotteryInfoSyncData` 的福袋同步解析。显示平台实际提供的活动标识、中奖名额、奖品数量和开奖时间；不会将其他房间同步消息误标为福袋。
- 新增 `WebcastPreviewCjRpMessage` 红包预告解析，与福袋分别显示。缺少的发送人、活动字段不补造，也不推测金额单位。
- 已使用指定公开直播间的脱敏真实消息回放，验证协议解码、采集回调、场次校验、数据库保存和分类读取链路。

## 礼物接收边界

- 2026-10-16 14:34:57～14:37:57，对直播间 100000009000 进行游客连接现场测试。期间用户反馈已发送「小心心」和「人气票」，连接正常收到房间状态，但原始 WSS 消息中没有收到礼物包。因此本版不宣称已解决游客连接的礼物下发问题。
- 平台未下发的消息无法通过列表或解码修复补回。礼物完整性仍需使用该主播的独立登录凭据做对照测试；请在应用内配置，不要在聊天中发送 Cookie。
- 网页活动入口、直播画面中的活动提示与 WSS 下发范围可能不同；仅记录实际收到的消息，不自动参与活动。

## 数据与更新

- 保持 schema v3，增加分类查询索引，不修改已有消息原文、场次统计和导出列。
- 沿用原安装位置、用户数据和更新签名。支持从 0.2.2 发起更新时暂停并保存监控任务，安装后重新打开应用恢复。
- 本版安装包与签名更新文件需由维护者手动上传 CDN，未上传前线上更新检查不会发现本版。
