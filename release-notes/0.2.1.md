# 氢看直播 0.2.1

本版加入红包/福袋活动消息解析、共享网络出口、HTTPS 代理订阅和归档记录清理，并调整开播排序、折叠与窗口界面。改进代理认证更新、直播状态提示及首次使用体验。继续只采集直播间消息，不播放或录制视频、音频。

## 红包与福袋活动

- 新增 8 种活动协议消息解析，统一归类为「红包/福袋」，可在实时消息中筛选，也参与默认月度导出。
- 已核实的活动标识、时间、奖励及条件等字段形成可读摘要；字段未提供时不推测。发送人未知时 ID 和名字保持为空。
- XLSX / CSV 仍为七列，「消息内容」保存活动摘要；原始结构化活动证据保存在数据库的 `payload_json`，不将其展开为新的导出列。
- 活动解码、界面、入库及导出已使用合成数据验证。指定房间 `100000007000` 经直连和 Orem 代理仅取得 HTTP 200，未取得有效房间元数据，因此没有活动 WSS 实包，不能声称已验证该房间真实红包/福袋接收。

## 多个任务共用出口

- 同一个代理可以分配给多个主播，每个房间仍使用独立的 WSS 消息连接和真实直播场次，不会合并房间消息。
- 默认允许本机直连参与均衡。新任务按各出口的任务数分配，正常连接保持原出口；关闭「直连参与均衡」后只使用代理，缺少可分配代理时等待。
- 每个出口分别限制正在建立的连接和并行 HTTP 请求，避免同时启动大量主播时集中发出请求。这些限额控制建连和请求过程，不是同时在线房间的数量上限。
- 444 / 429 会让相关出口的新增请求进入冷却；一个房间的业务拒绝不会直接关闭同出口其他正常消息连接。出现多个传输故障时复查出口健康，认证失败暂停新分配。
- 代理池页面显示各出口的任务数、正在建连数量和冷却状态。仅准备备用代理时，正在使用的直连负载仍正确显示。

## HTTPS 代理订阅

- 可添加 HTTPS URL 订阅，支持 Geonode、标准 JSON 代理数组和逐行代理地址。默认每 60 分钟刷新，也可手动刷新或移除。
- 添加订阅后异步获取候选，归入「已导入 / URL 订阅」来源；不会自动切换来源或启动监控。新候选经过健康检查后才参与分配。
- 刷新失败保留上次成功结果；来源明确返回空列表时撤销该来源的候选。删除订阅后，迟到的读取结果不会将它重新恢复。
- 手工导入与订阅重复时优先使用手工记录。URL、查询令牌和代理凭据使用当前 Windows 用户 DPAPI 加密，界面仅显示主机标签，不显示完整路径、令牌或密码。
- 读取仅支持公网 HTTPS，固定经校验的目标地址并验证 TLS，不跟随重定向；响应、记录数、等待时限和工作线程均有上限。订阅成功只代表取得候选，不代表代理已经可用。

## 更新已有代理的认证信息

- 再次导入同一地址时，账号、密码、协议及说明信息可以更新。预览区分别显示新增、更新、未变化和无效数量。
- 只有明确更换账号、密码或协议的导入项会重新获得检测机会；普通获取检测仍跳过本次运行已经失败的地址，不会清空其他代理或公共池的失败记录。
- 旧检测晚返回不会覆盖新凭据的待检测状态。HTTP CONNECT 407 与 SOCKS5 认证拒绝显示明确的认证失败提示，错误不包含凭据或原始代理 URL。

## 按范围删除已归档消息

- 在「月度归档」选择主播后，可按月份、直播场次，或这些主播的全部记录清理。月份与场次同时选择时取交集，删除包含范围内的全部消息类型。
- 先预览消息数和场次数，再确认删除；不接受缺少主播范围的请求。场次列表支持按月筛选与分页，切换月份会重置分页和选择。
- 删除前检查相关监控、导出和在途写入。操作在后台事务中执行，期间可继续查看界面并收起进度窗口；删除运行时阻止新的监控、导出或重复删除，避免竞态。
- 退出应用会请求取消删除；事务观察到取消时，尚未提交的更改回滚。取消生效前已完成提交的删除不撤回，请先导出需要保留的内容。监控任务、其他范围、运行日志与已有导出文件不受影响。

## 更准确的状态和首次使用

- 新安装首次启动主播列表为空，不再预置示例房间。升级仍保留已有主播、自定义昵称及合法旧配置；不会自动清空用户列表。
- 可在浏览器确认后手动标记黄色「非 PC 支持」，也可清除标记。标记只描述电脑端兼容性，消息是否已连接单独显示，不会改变监控行为。
- 不根据 HTTP 444、无效响应或隐藏网页提示自动判定「非 PC 支持」。开播状态只接受明确有效值，布尔或浮点异常值不会被误判为下播。
- 顶部窗口控制按钮调整尺寸、间距和图形，并在窗口失去焦点时显示灰色状态；关闭、最小化和最大化行为保持一致。
- 已确认开播的主播排在前面，按当前在线人数从高到低排列；未开播区域默认折叠，可以展开查看。未知状态保持单独判断，不当作未开播。
- 移除看板「开播优先」说明和底部整条状态栏，内容控件统一为轻圆角，保留外壳圆角及窗口控制行为。

## 同场次恢复累计监控时长

- 使用真实主播 ID 和直播场次标识累计已监控时长。同场次停止后重新开始、正常退出后重新打开，继续已保存的累计值，中断和停止间隔不计入。
- 进入新的真实场次重新计时，不使用网页入口或主播昵称猜测同一场。多个入口指向同一主播、同一场次时，不重复累计重叠的监控区间。
- 活跃期间定期保存检查点，停止和正常退出时保存最终已观察值。强制结束进程或断电只能恢复最近成功检查点，无法保证保留尚未落盘的最后几秒，不按离线时长补算。
- 累计值独立于聊天内容及真实开播时间；清理聊天不重置该场计时，也不修改服务端 `started_at`。从未记录过的新场次或旧版本数据不凭空补造累计时长。

## 升级、数据与验证边界

- 界面、后台、Rust 原生模块及安装器统一为 **0.2.1**。继续使用原安装身份、用户数据目录和签名公钥，无需重新导入已有配置。
- 内容库从 schema v1 自动事务迁移到 v2，保留全部原消息、场次、去重规则、自增序号及索引，并允许活动消息。失败或取消保留未提交前的旧库。**旧版应用不能打开升级后的 v2 库**，需要回退时须使用升级前完整备份；详细边界见归档升级说明。
- 沿用更新地址 `https://assets.checkpoint321.com/lilith/qingkan-live/latest.json`。0.1.0、0.1.1、0.2.0 的发行文件保留；维护者上传本版安装包、签名及清单后，旧版才能通过「检查更新」发现 0.2.1。
- 自动化测试覆盖共享出口、订阅取消、凭据更新、冷启动、手动标记和删除并发；删除及冻结程序检查使用临时合成数据，不删除真实用户记录。具体源码、成品和安装验收以随包评估记录为准。
- 本机 50 房间网络模拟与 300 生产线程归档压测不等于同数量真实直播持续连接。HTTPS 首页通过不保证房间接口、WSS 或长期可用；部分实际房间没有返回可用元数据，因此不能宣称它们已通过代理收到消息。
- 不自动上传 CDN。本地签名与安装包验收不替代上传后的线上检查、下载与升级验证。
