# 氢看直播 0.3.5

## 看板与入口

- 累计监控时长改为独立数字底片与中缝翻页，仅变化的数字翻动；启用减少动态效果时直接更新。
- 导航集中为「监控看板」「导出数据」「设置」三项，原月度归档入口更名为「导出数据」；实时消息通过看板中的「消息流」进入。

## 代理与诊断

- 新安装默认关闭代理池、使用本机直连；升级保留旧配置中明确保存的代理启用偏好。
- 代理功能移入设置并默认折叠。代理关闭时不自动拉取公共代理或刷新 URL 订阅，手动检测与刷新仍可使用。
- 调试模式默认关闭，正常连接、停止和未开播轮询不进入运行日志队列或磁盘，真实异常继续保留。排查时可在「设置 → 诊断」开启详细日志并查看；日志最多保留两份、各 8 MiB。

## 红包与福袋回看

- 活动在时间轴中使用固定 26×26 像素标记，与聊天数量面积图分开展示。悬停或键盘聚焦可查看活动信息，点击标记定位回放；播放到对应时刻时，黑色演示画面显示红包或福袋通知。
- 活动有明确的平台通知时间时据此定位；缺失时使用接收通知的观察时间，并注明「活动通知时间未知」及「观察记录」。开奖或结束时间单独展示，不当作通知时间，也不用于扩张回放时间轴。
- 聊天面积图继续仅统计有可靠平台时间的聊天。活动标记与通知来自实际归档，身份无法可靠确认时不推测合并或绘制标记；回放仍为黑色画面演示，未接入视频流。
