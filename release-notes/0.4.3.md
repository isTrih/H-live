# 氢看直播 0.4.3

- 新增直播打点：看板快捷记录，支持标题、备注、回看定位、精选选片与批量下载，重启后保留。
- 下载任务按日期分类，支持日期、状态和关键词检索，分页读取完整历史。
- 新增下载位置、文件夹规则和文件名规则设置，支持主播、日期、标题等变量、路径预览和自动创建目录。
- 下载重名自动追加序号，重复请求不重复排队，批量失败可继续。
- 回看时间轴显示真实世界时刻，设置支持选择时区，默认中国时间；保留录像时间缺口与跨日日期。
- 录像提前缓存后续最多 120 秒，预取后续分段，减少网络波动造成的卡顿。
- 修复长录像后段的弹幕面积图缺失，按完整录像时间映射重新分桶，保留消息时间空档。
