# 氢看直播 0.1.0

0.1.0 提供 Windows 多主播消息监控、按场次归档、月度导出和独立代理管理。

## 监控与归档

- 支持同时管理多个主播，批量粘贴直播间链接或数字 ID，按主播独立开始、停止、重试、改名和设置 Cookie。首次打开不自动开始监控。
- 专注直播间消息，不播放或录制视频、音频。保存聊天、表情、礼物、点赞、进入、社交和粉丝团等实际收到的内容；运行日志与内容分开。
- 使用稳定主播 ID 聚合同一主播，以平台真实 room_id 区分场次。同场网络重连延续原场次，有服务端消息 ID 时去重；没有实际场次 ID 时不拿入口 ID 代替。
- SQLite 保存内容，运行日志按日保存。支持选择多位主播、月份和消息类型，导出 XLSX / CSV，固定六列：主播、直播间场次、发消息人ID、消息类型、消息内容、发消息时间。
- XLSX 将长 ID 作为文本保存。CSV 对危险公式前缀进行保护并提示。未知发送者 ID 或发送时间留空；缺少发送时间时按接收月份归入，不伪造平台时间。旧版 JSONL 保留，不自动混入新导出。

## 看板与桌面体验

- Tauri / WebView2 桌面界面提供监控看板、实时消息、月度归档、运行日志、代理池和设置。宫格支持搜索、筛选、开播优先和连续虚拟滚动；批量选择模式中才显示复选框。
- 卡片突出主播名字、直播状态、本次监控记录的开播时长和当前在线人数。进入已开播房间时从任务开始计时；先等待开播时不把离线等待计入。同场重连保持计时，手动重启重置。
- 当前在线人数只用于内存显示，不写消息归档、不增加消息计数、不导出。未知或状态待确认显示「—」，不以累计观看数替代。
- 整卡点击打开居中详情，连接信息和独立 Cookie 可折叠；红色停止按钮与默认浏览器打开直播间操作分开。停止任务、切换页面和筛选互不混淆。
- 提供小电视应用标识、5 px 深色窗口边框及文字对齐调整。内置抖音美好体与寒蝉半圆体，设置会保存字体选择，字体许可随包提供。
- 支持单实例、窗口恢复聚焦和高 DPI；关闭时等待内容写入并回收后台进程。依赖随程序提供，用户无需安装 Python、Node.js 或 Excel；系统需要 WebView2。

## 代理与凭据

- 支持公共候选池及用户导入代理。可粘贴 JSON、代理 URL、四段文本或表格，也可选择 JSON / TXT / CSV / TSV 文件；预览会列出有效、重复和无效项目。
- 支持 HTTP CONNECT 和 SOCKS5 用户名密码认证，SOCKS5 使用远端 DNS。HTTP 请求与 WSS 消息连接共用同一房间租约，证书校验保持开启，不自动回退直连。
- Cookie 和导入代理凭据使用当前 Windows 用户 DPAPI 加密保存；预览、状态和报告不回显账号密码。用户原始导入文件仍需自行保管。
- 可在代理关闭时先获取并检测，启用时复用仍有效的结果。切换来源或代理/直连模式需先全部停止；导入、检测不会自动启动监控。
- 公共来源每批以 50 个新候选为目标，已导入来源每批最多检测 50 个。跳过当前已有及本次应用运行中失败的地址，重复点击不叠加批次；来源不足有界停止。50 是候选数量，不保证获得 50 个可用代理。
- 房间独占代理 IP，候选不足显示「等待代理」。首页通过仅表示初检成功；ProxyHub、ProxyClean 尚未成为自动获取来源。

## 稳定性与状态修复

- 修复连接前取消、HTTP 请求中停止、重复快速启停及旧连接回调造成的竞态，避免停止后继续写入或旧连接影响新任务。
- 使用共享心跳、受限签名并发、渐进建连和有界数据库写入队列；轮询与 UI 缓存有容量限制，后台操作不阻塞界面读取。
- 将房间接口业务拒绝与真实网络故障分开。此前在播时先两次约 5 秒显示「疑似下播，正在确认」；持续拒绝转为状态待确认，只有明确查询到下播才变更状态。业务拒绝保留代理租约，避免误判健康代理失效。
- 严格保留 TLS 校验，拒绝重定向初检，错误信息不直接输出认证 URL、Cookie 或原始导入内容。

## 代理实测与使用限制

- 按 200–300 个任务的管理与归档需求设计；已有本机 300 个模拟任务容量测试，但未完成 300 路真实直播或 24 小时连续运行验证。实际数量仍受平台、网络、代理和机器条件影响。
- ProxyHub 两枚公网 HTTP 代理完成各 45 秒真实互动内容接收；其中一枚再观察 90 秒收到 17 条（10 点赞、6 进入、1 社交），没有 chat。ProxyClean 一枚 SOCKS5 代理经独立诊断适配器完成 45 秒、7 条互动接收，不能追溯作为新增原生认证传输的真实验收。
- 用户提供的 33 枚认证 SOCKS5 本次为 30 枚认证拒绝、3 枚超时，独立 curl 复核一致，没有该批账号成功接收消息的证据。此前 SCDN 失败样本不代表所有公共代理来源不可用。
- 平台接口非官方，可能受登录、网络、访问限制或协议变化影响；只保存实际收到且成功入库的内容，不补历史，不保证消息完整性或长期连接。

## 版本更新

在「设置 → 关于与更新」可阅读当前版本日志、手动检查新版本，并查看新版本的更新内容。下载的更新包会经过签名验证；下载前和安装前分别检查后台状态，只有监控、导出和归档写入均已结束，后台正常退出后才安装，避免覆盖仍在使用的程序。无需为了查看更新而停止监控，安装时才需要满足空闲条件。

维护者手动上传更新包和 CDN 发布清单；线上更新链路仍需在文件上传后验证。若尚未发布新包或网络暂时不可用，检查更新会说明原因，不影响已有版本继续使用。
