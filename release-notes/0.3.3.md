# 氢看直播 0.3.3

## 直播互动回放

- 详情页移除头像和重复标题，精简直播状态、在线人数及累计监控时长。
- 新增黑色画面演示与归档聊天弹幕，支持播放、暂停、拖动时间轴和倍速回看；本版本暂未接入直播视频流。
- 时间轴以面积图呈现聊天消息数量，消息时间未知时单独提示，不编造位置。
- 直播场次改为剧集式卡片，悬停或键盘聚焦查看统计，点击切换场次。日期统一为 `26/10/25` 格式。
- 切换场次、关闭详情时清理回放任务；刷新保留播放位置及键盘焦点，当前场次跨场开播时同步跟随。

## AI 亮点分析

- 全局设置支持 OpenAI 兼容 API 地址、Key、上游模型获取与当前模型选择，所有主播共用。默认地址为 `https://llm-proxy.lilithgames.com/v1`；已保存的自定义地址继续生效。
- 手动将本场全部可用归档、活动、在线采样和状态拼接成一次 Prompt，寻找有聊天证据的互动亮点，以 💡 标在时间轴上并支持点击回看。
- 单次输入过大或模型上下文不足时明确提示，不截断、分批或自动重试模型请求。AI Key 由后台加密保存。
- 获取上游模型时保持停止监控等操作可用。分析设置入口直接跳转全局设置页。

## 使用范围

- AI 分析仅覆盖已监控归档，不能补采监控前或断线期间的聊天，也不代表已观看直播视频。
- 亮点依据发言账号和消息内容，不确认账号背后的自然人身份。实际可用模型与调用额度由配置的服务提供方决定。
