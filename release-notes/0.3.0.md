# 氢看直播 0.3.0

## 原生后端

- HTTP/WSS 消息采集、游客凭据、原生签名、心跳、任务调度和代理管理迁移至 Rust。
- 移除运行时 Python、PyO3、MiniRacer/V8 与 JavaScript 签名脚本；仍使用 Tauri WebView 的现有界面。
- 多房间共享异步运行时，按出口限制请求与建连速度，维持已建立的独立 WSS 长连接。

## 数据与功能

- 保留原有用户数据目录、SQLite 归档、场次身份、暂停续时、在线统计、本地发言质量分析、CSV/XLSX 导出与记录删除。
- 保留代理文本/JSON/HTTPS 订阅导入、失败候选排除、过期/退役处理及直连参与均衡。
- 移除登录 Cookie 设置入口和调用；只使用临时游客会话。旧登录字段不解密、不发送。
- 不再新增礼物记录；历史礼物继续可查询和导出。
- 保留每小时检查更新，以及确认更新后停止采集、完成写入、更新后恢复任务的流程。
- 升级时清理安装目录内可识别的旧 Python engine，避免更新模式遗留解释器；拒绝递归清理重解析的 engine 目录。用户消息归档继续保存在原数据目录。

## 兼容与限制

- 更新沿用既有应用标识和签名渠道；请先备份重要归档。
- 只记录实际收到并成功保存的消息，不补采历史或断线期间的内容。
- 平台 HTTP 444/429、访问限制和游客消息下发范围不会因为改用 Rust 而自动消失。

## 验证范围

- 173 项回归通过；使用 0.2.4 原生模块生成的合成数据库与 DPAPI 代理配置验证升级，历史六表逐值保留，CSV/XLSX 可导出。
- 离线模拟 300 个任务、50 条连接及集中断线重连通过，观察到 Rust 后端 RSS 峰值约 27.8 MiB；不包含 WebView，也不代表平台真实 50 房间长期可用。
- 真实游客 WSS 连接并保存过进入事件；观察窗口没有实际聊天，聊天链路由合成帧测试验证。
- 隔离安装器验证新装、旧版升级、卸载与数据保留；热更新继续采用原公钥及签名渠道。
